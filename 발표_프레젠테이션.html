2. 기획 배경

기존 방식의 문제점

기존 플러그인은 채팅창에만 의존하는 텍스트 기반으로, 사용자 입장에서 직관적이지 못했습니다.

해결 방안 및 목표

시각적인 GUI 인터페이스를 도입하고, 자바를 통해 안정적인 송금 시스템을 직접 구현하고자 했습니다.

3. 주요 기능

// 닉네임 변경 시에도 유지되도록 UUID 사용
public void saveData() {
    for (Map.Entry<UUID, Double> entry : balances.entrySet()) {
        dataConfig.set("balances." + entry.getKey().toString(), entry.getValue());
    }
    try {
        dataConfig.save(dataFile); // 즉시 저장하여 데이터 유실 방지
    } catch (IOException e) { e.printStackTrace(); }
}
